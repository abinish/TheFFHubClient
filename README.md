# The Fantasy Football Hub
This repo contains the website for the fantasy football hub.  This site is intended to bring interesting statistics and insights to any and all fantasy football players.


# Architecture
The fantasy football hub relies on it's backend API to manipulate every supported site into a single data model for the website to use and interpret.  This allows the UI to be agnostic of the integrated site and treat them all in the same fashion
